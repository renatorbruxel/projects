# Sales productivity and resource planning

This module supports its commercial decision with a shared metric context, inspectable facts and follow-up actions. It is one part of the connected five-module portfolio, presented as three case studies.

[Open the module](sales-league.html) · [Architecture, data, tests and limits](../docs/README_OPERATING_MODEL.md) · [Coverage and implementation status](../docs/IMPLEMENTATION_STATUS.md)

## Reproduce

From the repository root, run `python scripts/reproduce.py`, then `python -m http.server 8000`. Python 3.11+ and Node.js 18+ are required; the default path has no installed-package or credential dependencies.

## Governance and evidence

Metrics share the same contract, calendar, source classification and context. Observed educational CRM facts and deterministic synthetic planning are separate modes. Appropriate views include raw/filtered exports and drill-through evidence. Supporting SQLite views, data dictionary, generator and tests are in the root project.

The local workflow, role simulation and copilot are explicitly bounded reference functions. Production connectors, authentication, messaging and live language-model calls are outside this implementation. Career outcomes are not measured by synthetic demos. See the linked implementation register for concrete limits and the missing original quota-source dependency.

This independent reference implementation demonstrates analytical and operating-model patterns used in commercial performance work. It contains no employer code, data, schemas, screenshots, prompts, internal documentation, customer information or proprietary business logic. Public educational CRM provenance is retained separately.
